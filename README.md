# Elpriser – Analysverktyg

Detta projekt är en interaktiv konsolapplikation i Java som hämtar aktuella elpriser.

Projektet är utvecklat med Java och använder Javas inbyggda `HttpClient` för API-anrop samt Jackson för att parsa JSON-data.

# Reflektion

Jag upplever att Java är ett väldigt strikt språk att arbeta med jämfört med JavaScript.
Det har varit en utmaning att ställa om sig, speciellt när de gäller OOP.
JavaScript är enklare när man snabbt vill testa och skriva ihop funktionalitet, medan Java kräver mer struktur och noggrannhet från början.

Jag tycker ändå att det på något sätt har känts lite lättare att lära sig Java än när vi började med JavaScript. När vi började med JavaScript var vi helt nya och behövde lära oss grunderna från början. Nu när vi har börjat med Java har vi redan med oss mycket av tänket och grunderna från JavaScript, vilket gjort att det inte har känts som att vi börjat helt från noll igen.
